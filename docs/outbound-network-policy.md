# Outbound Network Policy

GuardianWAF treats outbound HTTP clients as SSRF-sensitive unless the integration is explicitly scoped to an operator-controlled private endpoint. Production code should not use `http.Get`, `http.Post`, `http.Head`, `http.DefaultClient`, or an unbounded `http.Client` for outbound integrations.

## Policy Matrix

| Integration | Private network policy | Redirect policy | Timeout policy | Response-size policy |
|---|---|---|---|---|
| Backend proxy targets | Private, loopback, link-local, and reserved targets are blocked by default. Operators must configure `allowed_upstream_cidrs` or `allow_private_upstreams`. | Reverse proxy target selection does not follow arbitrary discovery redirects. | Transport has explicit dial, TLS handshake, response-header, idle, and expect-continue timeouts. | Streams proxied responses; request inspection remains bounded by WAF body limits. |
| Proxy upstream health checks | Inherits the target/router private-network policy. | Redirects are not followed. | Explicit whole-request, dial, TLS handshake, response-header, idle, and expect-continue timeouts. | Health response body is not required for routing decisions. |
| AI provider calls | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets unless the provider is explicitly constructed with private endpoint allowance for controlled testing. | Redirect targets are validated before following. | Explicit whole-request, TLS, response-header, idle, and expect-continue timeouts. | Oversized provider responses are rejected before parsing. |
| AI model catalog | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets. | Redirect targets are validated before following. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized catalog responses are rejected before parsing. |
| Alert webhooks | Dashboard-managed and runtime targets must be HTTPS, include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets. | Redirect targets are validated before following with the same URL policy. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Response body is not trusted; delivery status is bounded to success/failure accounting. |
| GeoIP downloads | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets. | Redirect targets are validated before following. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized plain or decompressed downloads are rejected before writing the final cache file. |
| Threat-intel URL feeds | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets. | Redirect targets are validated before following unless a future config explicitly narrows that behavior. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized feed responses are rejected before updating entries. |
| API security JWKS | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, `.local`, and `.localhost` targets. | Redirect targets are validated before following. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized JWKS responses are rejected before parsing or key caching. |
| Virtual patch NVD client | Operator-supplied endpoints must be HTTP(S), include a host, omit URL userinfo/credentials, and avoid private, loopback, link-local, multicast, localhost, `.internal`, and `.local` targets. | Redirect targets are validated before following. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized NVD responses are rejected before parsing. |
| Planned SIEM exporter | No SIEM HTTP exporter runtime is present in the current tree. Future operator-supplied endpoints must define SSRF policy before release and should default to HTTP(S), host-required, credential-free, public-network targets unless private SIEM endpoints are explicitly operator-scoped. | Future runtime must validate or disable redirects before release. | Future runtime must define whole-request, dial, TLS, response-header, idle, and expect-continue timeouts before release. | Future runtime must bound export payloads and batch queues before release. |
| ACME client | CA directory and order URLs are operator-selected public ACME endpoints. Private-network SSRF filtering is not applied because ACME may use CA-controlled infrastructure, but redirects are disabled. | Redirects are not followed. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized ACME responses are rejected before parsing or certificate caching. |
| OCSP responders | Responder URLs come from certificate AIA data. Dial-time validation rejects private, loopback, link-local, multicast, and unspecified resolved IPs. | Redirects are not followed. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized OCSP response bodies are rejected before parsing, stapling, or caching. |
| hCaptcha and Turnstile verification | Fixed public verification endpoints only; dial-time validation rejects private, loopback, link-local, multicast, and unspecified resolved IPs. | Redirects are not followed. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Oversized verification responses are rejected before parsing. |
| Replay targets | Operator-configured target; can intentionally point at private replay infrastructure. | Follows only the explicit `follow_redirects` policy, which defaults to no redirects. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Replay request and response handling is bounded by replay configuration. |
| Canary health checks | Operator-configured target; can intentionally point at private canary infrastructure. | Redirects are not followed. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Health response body is not required for pass/fail. |
| Cluster sync peers | Private networks are intentionally allowed for operator-managed peers. | Redirects are not followed away from the configured peer endpoint. | Explicit whole-request, dial, TLS, response-header, idle, and expect-continue timeouts. | Sync payloads are bounded by cluster message handling. |
| Docker Unix-socket polling | Unix socket only; not an arbitrary TCP URL. | Docker API redirects are not part of the polling contract. | Explicit whole-request, response-header, idle, and expect-continue timeouts. | Docker API responses are parsed into bounded discovery state. |

## Code Review Rules

- New outbound HTTP integrations must define their private-network policy, redirect policy, timeout policy, and response-size policy before release.
- New outbound HTTP integrations must add regression tests for timeout/redirect behavior and private-network rejection when the integration accepts arbitrary URLs.
- `http.Get`, `http.Post`, `http.Head`, and `http.DefaultClient` must not be used directly by production outbound integration code. Construct a bounded client instead. `http.DefaultTransport` may only be used as a clone base before setting explicit dial, TLS, response-header, idle, and redirect behavior.
- Integrations that intentionally allow private networks must be operator-controlled and documented in the policy matrix.
